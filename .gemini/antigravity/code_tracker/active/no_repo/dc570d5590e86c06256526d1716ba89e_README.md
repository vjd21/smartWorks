# Simple Item Manager

A lightweight Python-based web application for managing items with a description. This project uses a native `http.server` with a SQLite database backend.

## Features

- **Add Items**: Create new items with a name and description.
- **List Items**: View all existing items.
- **Persistence**: Data is stored in a local SQLite database (`app.db`).
- **REST API**: Simple API endpoints for CRUD operations.

## Technology Stack

- **Backend**: Python 3 (`http.server`, `sqlite3`)
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Database**: SQLite

## Getting Started

### Prerequisites

- Python 3.x installed

### Running the Application

1.  Clone the repository (if not already local).
2.  Navigate to the project directory.
3.  Run the server:

    ```bash
    python3 server.py
    ```

4.  Open your browser and navigate to `http://localhost:8080`.

## Project Structure

- `server.py`: The main HTTP server and request handler.
- `database.py`: Database initialization and connection logic.
- `index.html`: The frontend user interface.
- `app.db`: SQLite database file (created automatically).

## API Endpoints

- `GET /api/items`: Retrieve all items.
- `POST /api/items`: Create a new item.
    - Body: `{"name": "Item Name", "description": "Item Description"}`
